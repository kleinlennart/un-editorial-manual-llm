# Historical

`United_Nations_Editorial_Manual.pdf` is the **1983** print edition of the United Nations Editorial Manual (Sales No. E.83.I.16), from the UN Digital Library (record 134841).

It is **superseded** by the [Editorial Manual Online](https://www.un.org/dgacm/en/content/editorial-manual). It is kept for reference only and is **not** part of the mirror, `llms.txt`, the skill or the rules.
